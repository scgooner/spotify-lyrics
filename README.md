# Spotify Lyrics - Fabric, Minecraft 26.3, Windows
Animated synced lyrics for whatever Spotify is playing. No Spotify login.
Keys: J toggle, [ and ] shift lyric timing by 0.25s.
Install: Fabric Loader 0.19.5+, Fabric API 0.162.0+26.3, Java 25. Drop the jar in .minecraft/mods.

## Get the jar (no PC tools needed)
1. Create a free GitHub repo and upload ALL files from this folder (including the .github folder).
   If .github didn't upload: Add file > Create new file, name it `.github/workflows/build.yml`, paste the contents from this zip.
2. Open the repo's Actions tab. The "Build mod" run starts by itself (or press Run workflow).
3. When it's green, open the run and download the artifact `spotifylyrics-26.3-jar` (a zip containing the jar).
